📝 Textuele back-up template —

Syntaxis legenda

' ' Invulveld met standaard invultekst. De tekst tussen de aanhalingstekens wordt getoond als er geen andere bevindingen zijn.
" " Idem — dubbele aanhalingstekens.
XXX Invulveld zonder standaard invultekst.
// Contextuele AI-tekst — niet in het eindresultaat, wel in de AI-prompt als context.
[ ] Label van het invulveld — zichtbaar in de template maar niet in de output.
[br] Regelsprong-markering — direct na een [ ]-label plaatsen zodat de enter samen met het label verborgen wordt (compacte weergave zonder lege regels).
{ } Conditioneel blok — enkel zichtbaar in de output als het veld effectief ingevuld werd.
Tekst Alle overige tekst is een label — de omschrijving of structuur van het invulveld. Verschijnt zowel in de template als in de uiteindelijke output.

Voorbeeld

BESLUIT:
XXX

- Blaas: 'Normaal.' // context voor AI
[Botpatroon:] 'Normaal.'
{Fractuur:} XXX
